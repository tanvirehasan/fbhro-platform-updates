# FBHRO Platform Updates

Public, signed installation packages for FBHRO Platform. Download the latest package from [Releases](https://github.com/tanvirehasan/fbhro-platform-updates/releases).

Site administrators install updates from **System → Software Updates → Check for updates → Update now**. Each client verifies the publisher signature and package checksums before installing. No hosting or GitHub password is required by the update button.

The update package contains application code and production dependencies. It contains no client database, environment credentials, uploaded documents or private signing keys. Client settings, uploads and existing data remain on each installation.

This repository distributes release assets. The application source repository and publisher signing key are maintained separately.
